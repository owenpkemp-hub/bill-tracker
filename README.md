# Bill Tracker

See how far out each bill is, and what checking looks like after it.

- Starts blank. Add your own bills and income, or tap **Load demo data** to see how it works.
- Demo data is fictional and clearly labeled.
- One Import area: drop or choose a screenshot, an Excel file (.xlsx/.xls), a .csv export, or a JSON backup from this app. Review the draft rows, then apply.
- Everything you enter stays in your own browser. Nothing is sent anywhere.
- Light / dark mode, and it is sized for a phone home screen.

Open the site in Safari, then Share > Add to Home Screen.
