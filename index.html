Import — screenshot or Excel, one place

Drop one file here, or tap to choose: a screenshot of your Excel Tracker, the Excel file itself (.xlsx / .xls), a .csv export, or a JSON backup from this app. The app reads it, shows you draft rows to fix, and only applies when you tap Apply. The file itself never leaves your device — OCR and Excel reading libraries download from a CDN only when you tap Read file.

Apply will also set your as-of date, balance, and budget from Excel. Clear these fields to keep your current as-of, balance, and budget instead.

Applying does not write back to Excel; it updates this app's browser data only. Unlabeled rows stay unlabeled — the app never invents a bill name.
